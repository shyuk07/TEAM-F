# stores API

상점 개설과 폐점. 모듈: `src/stores`
테이블: `stores` (상점주 정보는 `users`)

## 1. 상점 개설
| Method | URI (제안) | 권한 | 성공 |
| --- | --- | --- | --- |
| POST | `/v1/stores` | 상점주 (관리자 승인 완료) | 201 Created |

관리자 승인을 받은 상점주가 상점을 개설한다.

- 상점명은 가입 시 등록한 상호(`name`)로 자동 설정되며 입력받지 않는다.
- 주소는 서버에서 좌표로 변환하며, 변환에 실패하면 개설할 수 없다.
- 상점주 1인당 하나의 상점만 개설할 수 있다.
- 개설 후 상점명과 주소는 변경할 수 없다.
- 개설 시각이 `approval_at`에 저장된다.

**헤더**
- `Content-Type: application/json`
- `Authorization: Bearer {access_token}`

**요청 본문**
| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `pickup_address` | string | O | 픽업 주소 (최대 500자) |

```json
{
  "pickup_address": "서울특별시 강남구 테헤란로 123"
}
```

**응답**
| 필드 | 타입 | 설명 |
| --- | --- | --- |
| `id` | UUID | 상점 ID |
| `owner_id` | UUID | 상점주 ID |
| `name` | string | 상점명 (상점주 상호) |
| `pickup_address` | string | 픽업 주소 |
| `latitude` | double | 위도 (서버 변환) |
| `longitude` | double | 경도 (서버 변환) |
| `created_at` | datetime | 생성 시각 |
| `approval_at` | datetime | 개설 시각 |
| `closed_at` | datetime \| null | 폐점 시각. 개설 시 `null` |

**에러**
| HTTP | 메시지 |
| --- | --- |
| 400 | 주소를 입력해 주세요. |
| 400 | 주소를 찾을 수 없습니다. |
| 400 | 이미 개설된 상점이 있습니다. |
| 400 | 동일한 상점명과 주소의 상점이 이미 존재합니다. |
| 401 | 인증이 필요합니다. |
| 403 | 승인 대기 중인 상점주 계정입니다. |
| 403 | 상점주 권한이 필요합니다. |

> **확인 필요**
> - 주소 → 좌표 변환 방법 (외부 지오코딩 API인지, 테스트용 고정 값인지)
> - 상점주 승인 상태를 어디에 저장할지 (`users`에 컬럼이 없음)
> - "1인 1상점" 규칙에 맞춰 `db-schema` 스킬의 `schema.sql`에 `stores.owner_id UNIQUE`를 넣었습니다. 폐점 후 재개점도 같은 행을 다시 쓰는 방식이어야 합니다

## 2. 상점 폐점
| Method | URI (제안) | 권한 | 성공 |
| --- | --- | --- | --- |
| POST | `/v1/stores/{store_id}/close` | 상점주 (본인 상점) | 200 OK |

상점주가 본인 상점을 폐점한다.

- 진행 중이거나 예정된 할인 판매, 또는 픽업 대기 중인 예약이 있으면 폐점할 수 없다.
- 폐점 시 `closed_at`이 기록된다.
- 폐점된 상점에서는 상품 및 할인 판매를 등록할 수 없다.
- 폐점한 상점은 재개점할 수 있다.

**헤더**
- `Authorization: Bearer {access_token}`

**경로 매개변수**
| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `store_id` | UUID | 상점 ID |

**요청 본문:** 없음

**응답**
| 필드 | 타입 | 설명 |
| --- | --- | --- |
| `id` | UUID | 상점 ID |
| `name` | string | 상점명 |
| `closed_at` | datetime | 폐점 시각 |

**에러**
| HTTP | 메시지 |
| --- | --- |
| 400 | 이미 폐점된 상점입니다. |
| 400 | 진행 중이거나 예정된 할인 판매가 있어 폐점할 수 없습니다. |
| 400 | 픽업 대기 중인 예약이 있어 폐점할 수 없습니다. |
| 401 | 인증이 필요합니다. |
| 403 | 승인 대기 중인 상점주 계정입니다. |
| 403 | 본인 상점만 폐점할 수 있습니다. |
| 404 | 상점을 찾을 수 없습니다. |

> **확인 필요:** 재개점 API가 없습니다. 만든다면 `POST /v1/stores/{store_id}/reopen`을 제안합니다.
