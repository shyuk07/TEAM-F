# 상태와 계산 값

## 예약 (고객 화면)

| 조건 | 문구 | 태그 | 목록 |
|---|---|---|---|
| 결제 대기 | 결제 대기 | hot | 진행 중 |
| 예약 확정, 픽업 종료 전 | 예약 확정 | ok | 진행 중 |
| 픽업 완료 | 픽업 완료 | mute | 지난 예약 |
| 취소, cancelled_by = CUSTOMER | 취소됨 · "직접 취소" | mute | 지난 예약 |
| 취소, cancelled_by = STORE | 매장 사정으로 취소됨 | mute | 픽업 종료 전엔 진행 중, 이후 지난 예약 |
| 취소, 그 외·null | 취소됨 | mute | 지난 예약 |
| 취소, cancelled_by = SYSTEM | (고객 화면에 나오지 않음) | — | — |
| 예약 확정 + pickup_end 지남 | 픽업 시간 지남 | mute | 지난 예약 (화면 계산, DB 상태 아님) |

## 화면에서 계산하는 값

- **취소 마감** = 픽업 시작 − 1시간. 지나면 취소 링크 대신 회색 "취소 마감 지남 (17:00)".
- **판매 마감 N분 전** = 판매 마감 시각 − 지금.
- **수량 상한**(C2) = min(남은 재고, 5).
- **픽업 시간 지남** = 예약 확정 + pickup_end < 지금.
- **적립 예정** = 결제 금액 × 1% (반올림 규칙은 서버 응답 기준).
- **할인 등록 기본값**(O3): 판매 시작 = 지금, 픽업 시작 = 2시간 후, 판매 마감 = 픽업 시작, 픽업 2시간.

## 화면 상태 공통

- 로딩: Skeleton(카드 모양). 버튼 처리 중: 비활성 + "처리 중…".
- 빈 상태: EmptyState + 다음 행동 버튼 하나.
- 오류: 해당 입력 칸 바로 아래 `err`. 화면 전체 오류는 Notice.
