# TableRow

상점주·관리자 목록의 반응형 행. 720px 이상이면 5열 표(이름 1.4fr · 1fr · 1fr · 1fr · 동작), 미만이면 이름 아래에 나머지를 한 줄로 접습니다(`m mob`).

- 머리 행은 `tr th`(모바일에서는 첫 라벨만 보임).
- 넓은 화면 전용 칸은 `hide`, 모바일 전용 접힘 줄은 `mob`.
- 행 동작: 작은 버튼(승인·거부·정지) 또는 링크(강제 폐점). 위험 동작은 각자 M2 확인 시트를 엶.
- 선택 상태가 필요한 곳(M3 상세 패널)은 `sel`(fg 2px 외곽선). accent는 쓰지 않음.
- O1 픽업 목록은 표시 전용: 동작 칸이 비어 있음.
