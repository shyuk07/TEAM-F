# Input

44px 입력 칸. 라벨(`lbl`)은 칸 위, 오류 문구(`err`)는 칸 바로 아래에 둡니다.

- 필수는 라벨 끝에 " *". 제한은 라벨 괄호에: "비밀번호 * (8자 이상)", "수량 * (1~9999)".
- 읽기 전용(변경 불가)은 `in ro`(fill 바탕) + 라벨에 "(변경 불가)" 또는 🔒.
- 코드 입력(6자리 재설정 코드, 픽업 코드)은 mono 글꼴, 글자 간격 .15em(`in code`).
- 오류 문구는 무엇이 틀렸고 어떻게 고치는지: "코드가 맞지 않아요. 다시 확인해 주세요."
- 바꾼 값이 없으면 저장 버튼 비활성(PATCH는 바꾼 값만 보냄).
