# StatusTag

상태를 짧게 보여 주는 11px 테두리 태그. 색은 의미별 세 가지뿐입니다.

| 톤 | 클래스 | 예 |
|---|---|---|
| ok | `tag ok` | 예약 확정, 영업 중, 노출 |
| hot | `tag hot` | 결제 대기, 승인 대기, 상점 정지 |
| mute | `tag mute` | 픽업 완료, 취소됨, 매장 사정으로 취소됨, 픽업 시간 지남, 품절, 숨김, 판매 종료, 폐점, 거절됨 |

- 고객·상점주에게는 한국어만. 관리자 화면에서만 뒤에 상태 코드(`code-tag`, 예: `PENDING`)를 붙임.
- 상태 enum ↔ 문구 대응은 `states.md`.
