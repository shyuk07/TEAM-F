# Button

48px 알약형 버튼. 한 화면의 주 동작은 하나만 **pri**(accent)로, 되돌리기 어려운 확정은 **dark**로 씁니다.

| 변형 | 클래스 | 언제 |
|---|---|---|
| 주 버튼 | `btn pri` | 결제·등록·픽업 완료 등 화면의 목적. 금액이 붙으면 `btn pri split2`로 문구 왼쪽, 금액 오른쪽. |
| 확정(진한) | `btn dark` | 취소·탈퇴·폐점·정지처럼 되돌리기 어려운 동작의 확정. 항상 왼쪽에 기본 버튼 "취소"를 둠. |
| 기본(테두리) | `btn` | 두 번째 동작, "취소"·"돌아가기". |
| 작은 버튼 | `btn sm`, `btn sm pri` | 카드·행 안의 보조 동작(길찾기, 수정, 결제 이어하기). 40px. |

- 문구는 동사로 끝냄: "예약하고 결제", "픽업 완료", "1,000P 지급"(지급 금액을 버튼에 넣어 실수 방지).
- 처리 중에는 비활성 + "처리 중…". 비활성은 `aria-disabled="true"`(opacity .4).
- 모바일에서 주 버튼은 하단 고정 바(CtaBar) 안, PC(720px+)에서는 본문/우측 패널 안(`dk`).
- 위험 동작은 텍스트 링크로 먼저 노출하고(예: "판매 중단", "회원 탈퇴"), 확인 화면에서만 dark 버튼을 씀.
