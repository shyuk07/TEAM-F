# BottomSheet

모바일 확인·선택 시트. 뒤는 가로 줄무늬 딤(`dim`), 시트는 위 두 모서리 16px + shadow-sheet.

- 구성: 질문 제목(17px) → 결과 설명 한 줄(muted) → 버튼 세로 배치.
- 버튼 순서: 확정이 위(dark, 또는 실수 방지가 우선이면 pri "계속하기"), 아래 "취소"(기본), 덜 중요한 선택은 링크.
- 쓰는 곳: 로그아웃(C10), 결제 나가기(C3a), 위치·반경(C1a), 계정 메뉴(O8), 재고 조정(O10). PC에서는 드롭다운·우측 패널로.
- 시스템 confirm() 대화상자는 쓰지 않음.
