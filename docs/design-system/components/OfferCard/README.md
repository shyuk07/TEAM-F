# OfferCard

고객 홈(C1) 목록의 할인 카드. 76px 썸네일 + 정보 열, 카드 사이는 1px 구분선.

정보 순서(모든 카드 같은 형식):

1. 상점명 · 거리(위치 권한 없으면 거리 숨김)
2. 상품명(`t`)
3. 가격: 할인율(accent, 굵게) · 할인가(굵게) · 정가(취소선, muted)
4. "픽업 **오늘 18:00–20:00**"
5. "판매 마감 N분 전"(accent `cd`) + "남은 N개" — 품절이면 이 줄 대신 `tag mute` "품절"

- 사진은 4:3로 잘라 정사각 썸네일에 맞춤, 없으면 기본 그림.
