# 문구

## 말투

- 해요체, 짧게. 예: "결제가 완료됐어요", "로그아웃할까요?"
- 서버 오류 중 계정·보안 관련은 합니다체 그대로: "이메일 또는 비밀번호가 올바르지 않습니다."
- 사용자에게 보이는 이름으로: "내 예약", "포인트", "매장 사정으로 취소됨". 내부 이름(cancelled_by, RESTORE)은 쓰지 않습니다.

## 버튼·링크

- 버튼은 동사로 끝: "예약하고 결제", "픽업 완료", "판매 중단", "1,000P 지급".
- 확인 화면 버튼은 질문과 같은 말: 질문 "로그아웃할까요?" → 버튼 "로그아웃".
- 취소 계열은 "취소"(닫기), 예약을 없애는 동작은 "예약 취소"로 구분.
- 화면 이동 행은 끝에 "›", 설계 문서에서는 대상 화면 번호를 붙임(C8 ›).

## 오류·안내

- 무엇이 틀렸는지 + 어떻게 고치는지: "코드가 맞지 않거나 만료됐어요. 코드를 다시 받아 주세요."
- 사과·모호한 말 없이. 보안상 여러 원인은 한 문구로 합침(코드 오류·만료·횟수 초과 → 같은 문구).
- 결과를 미리 알림: "결제하지 않으면 식빵 모둠 2개가 계속 묶여 다른 사람이 살 수 없어요."
- 할 수 없는 약속은 쓰지 않음: 알림 기능이 없으므로 "고객에게 알림을 보냈어요" 같은 문구 금지.

## 숫자·시간 표기

| 항목 | 형식 | 예 |
|---|---|---|
| 금액 | 천 단위 쉼표 + "원" | 11,500원 · 정가는 "원" 없이 취소선 12,000 |
| 할인율 | 정수 % | 50% |
| 포인트 | 천 단위 쉼표 + "P", 증감은 +/− | 1,240P · +115P · −500P |
| 포인트 사용 | 100P 단위 | 500 |
| 적립 | 결제 금액의 1% | 결제 후 115P 적립 (1%) |
| 시간대 | 24시간, en dash | 18:00–20:00 |
| 날짜(목록) | MM/DD | 11/07 |
| 남은 시간 | "판매 마감 N분 전" / "N시간 N분 전" | 판매 마감 42분 전 |
| 수량 | "× N", 남은 것은 "남은 N개" | 식빵 모둠 5종 × 2 |
| 픽업 코드 | 영문 대문자 1 + 숫자 5 | A12345 |
| 거리 | 소수 1자리 km | 0.4km |

- 구분자는 가운뎃점 " · ": "망원베이커리 · 0.4km".
- 취소 가능 시각 = 픽업 시작 − 1시간: "취소 가능 오늘 17:00까지 (이후 취소 불가)".
