  • 취소 구분은 예약 응답의 cancelled_by로 표시(백엔드 반영됨 #44, 내 예약 목록과 취소 응답에 들어감): CUSTOMER → "직접 취소", STORE → "매장 사정으로 취소됨", 그 외·null → "취소됨". SYSTEM(탈퇴 회원 예약)은 고객 화면에 나오지 않음.
  • 미수령(노쇼): 픽업 종료 후에도 DB 상태는 "예약 확정"으로 남음 → "픽업 시간 지남"은 DB 상태가 아니라 화면이 계산해 표시(예약 확정 상태 + pickup_end가 지남). 환불·상태 전이 규칙은 백엔드에서 정해야 함(확인 필요).
