# 마감직전

마감 직전 남은 상품을 할인가로 예약하고 매장에서 픽업하는 앱의 디자인 시스템입니다. 고객·상점주·관리자 37개 화면 와이어프레임에서 뽑았고, 다른 LLM이나 개발자가 이 문서만 보고 같은 화면을 구현할 수 있게 정리했습니다.

## 이 시스템을 읽는 순서

1. **README.md**(이 문서): 원칙, 색·글자·간격 규칙, 컴포넌트 목록.
2. **tokens.json**: 모든 토큰 값(라이트·다크). 생성된 `tokens.css`는 토큰마다 CSS 변수(`--fg`, `--s3`, `--r-pill` …)를 정의합니다.
3. **components/bundle.css**: 컴포넌트 클래스 전부. `tokens.css` 다음에 불러옵니다. 클래스 이름은 와이어프레임 원본과 같습니다.
4. **components/<이름>/README.md**: 컴포넌트별 규칙, `preview.html`: 마크업 예시.
5. **layout.md**: 역할별 셸, 반응형 기준, 화면 골격, 화면 연결 지도.
6. **content.md**: 문구·숫자·시간 표기.
7. **states.md**: 상태 enum ↔ 한국어 문구, 화면에서 계산하는 값.
8. **screens.md**: 37개 화면 명세(API, 컴포넌트, 화면 문구, 동작 메모).
9. **api-map.md**, **open-issues.md**: 화면별 엔드포인트, 아직 정해지지 않은 항목.

## 원칙

- **기능이 먼저, 꾸밈은 최소.** 회색조 바탕에 강조색 하나. 상자·테두리는 떼어 보여 줄 묶음에만.
- **accent는 돈과 시간과 오류에만.** 결제 버튼, 할인율, "판매 마감 N분 전", 오류 문구, 경고 상자. 선택 상태·장식·링크에는 쓰지 않습니다. 선택은 `fg`(진한 칩, 2px 외곽선).
- **ok는 성공·정상에만.** 예약 확정, 영업 중, 픽업 완료 확인.
- **되돌리기 어려운 동작은 확인 화면을 거친다.** 진입은 조용한 텍스트 링크, 확정은 진한(`btn dark`) 버튼, 왼쪽에 "취소". 결과(환불액, 소멸 포인트, 막는 항목)를 확정 전에 보여 줍니다.
- **상태는 사람이 읽는 말로.** 고객·상점주에게는 한국어만, 관리자 화면에서만 상태 코드를 함께 씁니다.
- **로그인은 필요할 때만.** 앱은 비로그인 홈(C1)으로 열리고 "예약하고 결제"에서만 로그인합니다.

## 색

| 토큰 | 라이트 | 다크 | 쓰는 곳 |
|---|---|---|---|
| `bg` | #f3f3f1 | #161615 | 앱 바깥 페이지 |
| `paper` | #ffffff | #1f1f1d | 앱 화면, 카드, 시트, 입력 칸 |
| `fg` | #1d1d1b | #ecece8 | 글자, 선택 칩, 현재 탭, dark 버튼 |
| `muted` | #56564f | #a8a8a0 | 보조 글자, 라벨, 링크 |
| `line` | #c9c9c3 | #3d3d39 | 구분선, 테두리 |
| `fill` | #ecece7 | #2b2b28 | 읽기 전용 칸, 작은 버튼, 코드 상자, 스켈레톤 |
| `accent` | #c2410c | #ff8a50 | 결제·마감 임박·오류만 |
| `on-accent` | #ffffff | #ffffff | accent 위 글자 |
| `ok` | #2b7a3a | #5cc46f | 성공·정상만 |

> 대비 주의: 다크 테마에서 `on-accent`(#ffffff) on `accent`(#ff8a50)는 약 2.3:1로 4.5:1 기준에 못 미칩니다. 원본 값을 그대로 두었으니 다크 값(예: `fg` 라이트 값 #1d1d1b)을 정해 주세요.

## 글자

- 글꼴: **IBM Plex Sans KR**(400·600·700) 본문·제목, **IBM Plex Mono**(500·600) 픽업 코드·상태 코드. Google Fonts에서 불러옵니다.
- 앱 안 기본 13px / 1.5. 보조 12px, 태그 11px, 버튼 15px 700, 화면 제목 20px 600, 시트 제목 17px.
- 숫자가 세로로 맞아야 하는 곳(금액, 포인트, kv 행)은 `font-variant-numeric: tabular-nums`.

## 간격·모서리·크기

- 간격 `s1`–`s5` = 4·8·12·16·24px. 묶음 안 8, 블록 사이 12, 화면 여백 16(모바일)·24(PC).
- 모서리: 태그 4, 상자·입력 6, 시트 16, 버튼·칩 알약(999).
- 터치: 칩·입력 44px 이상, 주 버튼 48px, 작은 버튼 40px, 목록 행 52px.
- 그림자는 둘뿐: 하단 고정 바(`shadow-cta`), 바텀시트(`shadow-sheet`).

## 컴포넌트

| 묶음 | 컴포넌트 |
|---|---|
| Actions | Button, Chip |
| Forms | Input, Stepper, RolePicker, PhotoSlot |
| Content | OfferCard, Box(+KeyValue), PickupCode, ListRow, TableRow |
| Navigation | AppBar, TabBar, CtaBar |
| Overlays | BottomSheet |
| Status | StatusTag, Notice, EmptyState, Skeleton |

구현할 때 직접 만들어야 하는 것: 아이콘(와이어프레임은 ←, ✕, ›, ◎ 문자와 가입 화면 선 아이콘 2개만 씀), 상품 사진 기본 그림, 지도·길찾기 연결.

## 아이콘·이미지

- 아이콘은 1.8px 선, 둥근 끝, `currentColor`. 가입 화면의 고객(장바구니)·상점주(가게) 아이콘이 기준입니다(RolePicker 미리보기 참고).
- 사진 자리는 45° 빗금(`fill`) + 점선 테두리. 상품 사진은 4:3, 상품당 1장.
- 로고는 아직 없어서 "마감직전" 글자(700)로 씁니다.
