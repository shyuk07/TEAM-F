# catalog 도메인 요구 조건 — 할인 상품

상태: 확정 (확정일: 2026-11-06)
결정 과정: 확정 직전 버전의 git 이력

## 범위

- 포함: 할인 상품 하나의 등록·수정·중단·재개·재등록·재고 조정·조회 규칙, 재고 이력, 관리자 정지가 할인 상품에 미치는 규칙, 공개 목록(주변 할인 목록·상점 할인 목록)의 노출 규칙
- 포함: 상품 요구 조건(`docs/requirements/catalog.md`)에서 옮긴 항목 — 한 상품당 진행 중인 할인 상품 1개, 중단한 할인 상품 다시 살리기
- 제외: 예약·결제·환불의 규칙. 할인 상품 규칙이 예약을 **조건으로만** 참조하는 경우(예약 존재 여부, 예약 일괄 취소 요청)는 포함한다.
- 제외: 상점 폐점이 할인 상품에 미치는 처리(상점 요구 조건)
- 제외: 거리 계산·정렬·쪽 나누기 같은 조회 방식

## 용어
| 용어 | 정의 |
| --- | --- |
| 할인 상품 | 한 상품에 할인 가격·수량·판매 기간·픽업 기간을 정해 판매하는 단위. 상품과 별개 개념이다 |
| 상품 | 상점이 등록한 품목. 상품 요구 조건(`docs/requirements/catalog.md`)의 정의를 따른다 |
| 정상 가격 | 상품의 할인 전 가격. 할인 상품 등록·수정 시점의 상품 정상 가격을 기준으로 한다 |
| 할인 가격 | 할인 상품의 판매 가격 |
| 할인율 | 정상 가격 대비 할인 가격이 줄어든 비율(정수 %) |
| 최초 수량 | 할인 상품에 처음 입고한 수량. 수정·수동 증가로 늘거나 줄 수 있다 |
| 남은 수량 | 현재 판매할 수 있는 수량 |
| 판매 기간 | 판매 시작 시각부터 판매 마감 시각까지 |
| 픽업 기간 | 픽업 시작 시각부터 픽업 마감 시각까지 |
| 판매 예정 / 판매 중 / 품절 / 종료 / 정지 | 할인 상품이 보이는 상태. "상태와 전이" 절에서 정의한다 |
| 중단 | 상점주가 할인 상품의 판매를 멈추는 행위. 중단된 할인 상품은 "중단됨" 표시를 가진다 |
| 재개 | 중단된 할인 상품을 판매 마감 전에 다시 판매하는 행위 |
| 재등록 | 기존 할인 상품을 종료하고 같은 상품에 새 할인 상품을 등록하는 행위 |
| 재고 조정 | 상점주가 남은 수량을 수동으로 늘리거나 줄이는 행위 |
| 재고 이력 | 수량 변화마다 남는 기록(증감량·사유·기록자·시각). 추가만 되고 바뀌지 않는다 |
| 진행 중인 할인 상품 | 중단되지 않았고 판매 마감 전인 할인 상품. 관리자가 정지한 할인 상품도 포함한다 |
| 관리자 정지 | 관리자가 할인 상품을 정지하는 행위. 정지는 되돌릴 수 없다 |
| 공개 노출 상점 | 승인되었고, 폐점되지 않았고, 정지되지 않은 상점 |
| 상점주 | 상점을 소유한 회원 |

## 불변식
- REQ-1. 할인 상품은 반드시 한 상품에 속하며, 소속 상품은 바뀌지 않는다.
- REQ-2. 할인 가격은 1 이상의 정수이고, 그 할인 상품이 속한 상품의 정상 가격보다 작다.
- REQ-3. 최초 수량은 1 이상 9,999 이하의 정수이다.
- REQ-4. 남은 수량은 0 이상이고 최초 수량 이하이다.
- REQ-5. 판매 마감 시각은 판매 시작 시각보다 늦다.
- REQ-6. 픽업 마감 시각은 픽업 시작 시각보다 늦고, 판매 마감 시각과 같거나 늦다. 픽업 시작 시각과 판매 기간 사이에는 제약이 없다.
- REQ-7. 등록·수정이 끝난 시점에 판매 마감 시각은 현재 시각보다 늦어야 한다.
- REQ-8. 판매 시작 시각을 정하지 않고 등록하면 등록 시각이 판매 시작 시각이 된다.
- REQ-9. 한 상품에 진행 중인 할인 상품은 1개까지다(관리자가 정지한 할인 상품도 센다).
- REQ-10. 노출 중단된 상품에는 할인 상품을 등록·재등록·재개할 수 없다.
- REQ-11. 할인율은 (정상 가격 − 할인 가격) × 100 ÷ 정상 가격을 정수로 버림한 값이다.
- REQ-12. 남은 수량이 바뀔 때마다 재고 이력이 남는다. 한 할인 상품의 재고 이력 증감량 합은 그 할인 상품의 남은 수량과 같다. 단, 종료·중단으로 남는 수량은 이력 없이 그대로 둔다.
- REQ-13. 재고 이력은 증감량이 0이 아니고, 사유는 없거나 200자 이하이며, 한 번 남은 뒤 바뀌거나 지워지지 않는다.
- REQ-14. 최초 수량을 수정하면 남은 수량은 같은 증감량만큼 바뀐다(새 최초 수량으로 다시 채우지 않는다). 그 결과 남은 수량이 0 미만이 되면 수정이 성립하지 않는다.
- REQ-15. 재고를 수동으로 줄이면 남은 수량만 줄고 최초 수량은 그대로다. 늘리면 둘 다 늘고, 최초 수량이 9,999를 넘으면 성립하지 않는다.
- REQ-16. 할인 상품 수정은 여러 항목을 한 번에 바꿀 때 바꾸지 않은 항목과 합친 전체 값이 REQ-2~REQ-7을 지키는 경우에만 반영되고, 하나라도 어기면 아무것도 바뀌지 않는다. 바꿀 항목이 없으면 수정이 성립하지 않는다.
- REQ-17. 취소되지 않은 예약이 한 건이라도 있는 할인 상품은 판매 조건(가격·수량·시각)을 수정할 수 없다. 예약이 모두 취소됐으면 수정할 수 있다.
- REQ-18. 재등록은 기존 할인 상품의 종료와 새 할인 상품의 등록이 함께 일어나거나 둘 다 일어나지 않는다. 기존 할인 상품의 예약과 남은 수량은 그대로 둔다.
- REQ-19. 할인 상품의 중단·종료는 재고와 재고 이력을 바꾸지 않는다.
- REQ-20. 취소 가능 기한은 픽업 시작 시각 1시간 전이며, 할인 상품의 상태와 상관없이 같은 방식으로 계산한다.
- REQ-21. 관리자가 정지한 할인 상품은 상점주가 수정·중단·재개·재등록·재고 조정할 수 없다.
- REQ-22. 신규 예약은 판매 중 상태인 할인 상품에만 성립한다. 이미 성립한 예약은 할인 상품의 상태(중단·종료·정지)와 상관없이 자기 상태로 진행한다.

| 중단(방법 2: 판매 중단) | 진행 중 → 중단됨, 선택 시 예약 일괄 취소 요청 | 상점주: 허용 / 그 외: 불가 | 본인 상점, 정지 아님. 판매 마감이 지난 할인 상품도 중단할 수 있다. 상점이 폐점이어도 할 수 있다. 사유 필수. 픽업 완료된 예약이 있으면 예약 일괄 취소와 함께 하는 중단은 성립하지 않는다 |
| 재개 | 중단됨 → 진행 중 | 상점주: 허용 / 그 외: 불가 | 본인 상점, 판매 마감 전, 상점이 폐점이 아님, 상품이 노출 중, 같은 상품에 다른 진행 중인 할인 상품 없음, 정지 아님. 취소된 예약은 되살아나지 않는다 |
| 재등록 | 기존 할인 종료 + 새 할인 등록 | 상점주: 허용 / 그 외: 불가 | 본인 상점, 기존 할인 상품이 중단되지 않음(판매 마감이 지나도 가능), 상점이 폐점·미승인이 아님, 상품이 노출 중, 정지 아님 |
| 재고 조정 | 남은 수량 증감 | 상점주: 허용 / 그 외: 불가 | 본인 상점, 중단되지 않음(판매 마감만 지난 할인 상품은 허용), 정지 아님, 증감량 0 아님 |
| 관리자 정지 | 진행 중 → 정지 | 관리자: 허용 / 그 외: 불가 | 진행 중인 할인 상품만. 사유 필수. 이미 정지했거나 판매가 끝난 할인 상품은 정지할 수 없다 |
| 할인 상세 조회 | 할인 상품 하나 읽기 | 누구나 허용(인증 없이) | 중단·종료·품절 할인 상품, 폐점 상점·노출 중단 상품의 할인 상품도 보인다. 정지된 할인 상품과 정지된 상점의 할인 상품은 상점주 외에는 존재하지 않는 것처럼 다룬다 |
| 상점 할인 목록 | 상점 하나의 할인 상품 목록 읽기 | 누구나 허용 | 상태를 지정하지 않으면 진행 중인 할인 상품만 나온다. 종료된 것은 지정할 때만. 상점주 외에는 공개 노출 상점의, 노출 중 상품의, 정지되지 않은 할인 상품만 보인다(주변 할인 목록과 같은 기준). 상점주는 본인 상점 것을 모두 본다 |
| 주변 할인 목록 | 여러 상점의 할인 상품 찾기 | 누구나 허용(인증 없음), 주체별 차이 없음 | 공개 노출 상점의 노출 중 상품에 속한 할인 상품만. 정지된 할인 상품은 나오지 않는다. 상점주라도 예외 없음 |

## 상태와 전이

할인 상품의 상태는 시간이 지나면 저절로 바뀐다(판매 시작·마감). 보이는 상태는 아래 순서로 판정한다.
1. 관리자가 정지했으면 정지
2. 중단됐으면 종료
3. 판매 마감이 지났으면 종료
4. 판매 시작 전이면 판매 예정
5. 남은 수량이 0이면 품절
6. 그 외 판매 중

| 현재 상태 | 행위(트리거) | 다음 상태 | 차단 조건 |
| --- | --- | --- | --- |
| (없음) | 등록(판매 시작이 미래) | 판매 예정 | 주체와 정책 "할인 등록" 조건, REQ-2~7 위반 |
| (없음) | 등록(그 외) | 판매 중 | 위와 같음 |
| 판매 예정 | 판매 시작 시각 도달 | 판매 중(남은 수량 0이면 품절) | — |
| 판매 중 | 남은 수량 0 | 품절 | — |
| 품절 | 남은 수량 증가 | 판매 중(판매 시작 전이면 판매 예정) | — |
| 판매 예정·판매 중·품절 | 판매 마감 시각 도달 | 종료 | — |
| 판매 예정·판매 중·품절 | 단순 중단 | 종료(중단됨) | 정지됨 |
| 판매 예정·판매 중·품절 | 판매 중단 | 종료(중단됨) | 정지됨, 예약 일괄 취소 선택 시 픽업 완료 예약 있음 |
