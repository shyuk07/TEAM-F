# catalog 도메인 요구 조건 — 상품

상태: 확정 (확정일: 2026-11-06)
결정 과정: 확정 직전 버전의 git 이력

## 범위

- 포함: 상품 하나의 등록·수정·노출 중단·재노출·조회 규칙
- 제외: 할인 상품 자체의 규칙, 상점 폐점이 상품에 미치는 처리. 상품 규칙이 할인 상품이나 상점 상태를 **조건으로만** 참조하는 경우는 포함한다.
- 제외된 결정의 위치: 아래 "범위 밖으로 옮긴 항목"

## 용어
| 용어 | 정의 |
| --- | --- |
| 상품 | 상점이 판매하려고 등록한 품목. 할인 상품의 대상이 된다 |
| 할인 상품 | 한 상품에 할인 가격·수량·판매 기간을 정해 판매하는 단위. 상품과 별개 개념이며, 이 문서에서는 조건으로만 참조한다 |
| 진행 중인 할인 상품 | 판매가 중단되지 않았고 판매 마감 전인 할인 상품 |
| 상품 등록 | 상점주가 본인 상점에 새 상품을 만드는 행위 |
| 상품 수정 | 등록된 상품의 이름·카테고리·설명·정상 가격·이미지를 바꾸는 행위 |
| 노출 중 / 노출 중단 | 상품의 두 상태 |
| 재노출 | 노출 중단된 상품을 다시 노출 중으로 바꾸는 행위 |
| 정상 가격 | 할인 전 가격 |
| 상점주 | 상점을 소유한 회원 |

## 식별자
| 대상 | 형식 | 생성 방식 | 유일성 범위 |
| --- | --- | --- | --- |
| 상품 ID | UUID | 시스템이 생성 | 전체 상품 |
| 상품명 | 문자열 | 상점주가 입력 | 유일하지 않음. 같은 상점에서도 같은 이름을 여러 번 쓸 수 있다 |

## 불변식
- REQ-1. 상품은 반드시 한 상점에 속하며, 소속 상점은 바뀌지 않는다.
- REQ-2. 상품명은 앞뒤 공백을 뺀 뒤 1자 이상 200자 이하이며, 항상 있어야 한다.
- REQ-3. 정상 가격은 1 이상 2,147,483,647 이하의 정수이며, 항상 있어야 한다. 범위를 넘는 값은 입력 오류로 거부한다.
- REQ-4. 카테고리는 없을 수 있다. 있으면 앞뒤 공백을 뺀 뒤 1자 이상 80자 이하의 자유 입력 문자열이다.
- REQ-5. 설명은 없을 수 있으며, 길이 상한은 없다.
- REQ-6. 상품 이미지는 0개 이상 10개 이하이며, 각 이미지 주소는 공백일 수 없다. 이미지 목록 자체는 항상 있다(비어 있을 수 있음).
- REQ-7. 새로 등록된 상품은 노출 중 상태이다.
- REQ-8. 진행 중인 할인 상품이 있으면, 상품의 정상 가격은 그 할인 가격보다 커야 한다.
- REQ-9. 노출 중단된 상품에는 할인 상품을 등록할 수 없다.
- REQ-10. 상품 수정은 여러 항목을 한 번에 바꿀 때 모두 규칙을 지키는 경우에만 반영되고, 하나라도 어기면 아무것도 바뀌지 않는다. 바꿀 항목이 하나도 없으면 수정이 성립하지 않는다.

## 주체와 정책
| 정책 | 허용 행위 | 주체별 허용 여부 | 추가 조건(소유·상태) |
| --- | --- | --- | --- |
| 상품 등록 | 새 상품 만들기 | 상점주: 허용 / 비회원·일반 회원·관리자: 불가 | 본인 상점, 상점이 폐점·미승인이 아님(폐점을 먼저 판단) |
| 상품 수정 | 이름·카테고리·설명·정상 가격·이미지 변경 | 상점주: 허용 / 그 외: 불가 | 본인 상점. 노출 중단 상품과 폐점 상점의 상품도 수정할 수 있다 |
| 노출 중단 | 노출 중 → 노출 중단 | 상점주: 허용 / 그 외: 불가 | 본인 상점, 진행 중인 할인 상품이 없음 |
| 재노출 | 노출 중단 → 노출 중 | 상점주: 허용 / 그 외: 불가 | 본인 상점, 상점이 폐점이 아님 |
| 노출 중 상품 조회 | 상품 읽기 | 누구나 허용 | 상점이 폐점이 아님 |
| 폐점 상점의 상품 조회 | 상품 읽기·검색 | 상점주(본인 상점): 허용 / 그 외: 불가(존재하지 않는 것처럼 다룸) | — |
| 노출 중단 상품 조회 | 상품 읽기 | 상점주(본인 상점): 허용 / 그 외: 불가(존재하지 않는 것처럼 다룸) | — |

## 상태와 전이
| 현재 상태 | 행위(트리거) | 다음 상태 | 차단 조건 |
| --- | --- | --- | --- |
| (없음) | 등록 | 노출 중 | 상점 폐점·미승인, REQ-2~6 위반 |
| 노출 중 | 노출 중단 | 노출 중단 | 진행 중인 할인 상품이 있음 |
| 노출 중단 | 노출 중단 | (변화 없음) | 이미 노출 중단 상태라 거부 |
| 노출 중단 | 재노출 | 노출 중 | 상점이 폐점됨 |
| 노출 중 | 재노출 | (변화 없음) | 이미 노출 중 상태라 거부 |
| 노출 중·노출 중단 | 수정 | (상태 유지) | REQ-2~6·REQ-8·REQ-10 위반 |

- 소멸: 물리 삭제 없음. 노출 중단으로만 처리한다.
- 상점이 폐점된 동안 그 상점의 상품은 상태와 관계없이 상점주 외에는 노출되지 않는다.
- 재노출해도 예전 할인 상품은 자동으로 되살아나지 않는다.
