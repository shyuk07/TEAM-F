사용자: 설명은 제한 없어.

### RQ-7. 상품을 재노출할 때 할인 상품은 어떻게 되나요?
대상: 상태와 전이, REQ-9
배경: 1회차 답변 "상품은 다시 노출 가능, 할인 상품은 노출 불가"를 반영했습니다. 그런데 현재 설계에는 판매를 중단한 할인 상품을 마감 전에 다시 살리는 기능이 있습니다(design §4 "할인 재개", Q19). 답변이 아래 중 어느 뜻인지 확인이 필요합니다.
제안: (가) 상품을 재노출해도 예전 할인 상품은 자동으로 되살아나지 않는다. 할인 판매를 다시 하려면 새 할인 상품을 등록한다. 상품 재노출과 무관하게, 중단한 할인 상품을 다시 살리는 기존 기능은 유지한다(REQ-9를 지키는 한).
다른 해석: (나) 한 번 중단된 할인 상품은 어떤 경우에도 다시 노출할 수 없다(기존 "할인 재개" 기능 제거).
사용자: 상품은 다시 노출할수 있음. 하지만 할인 상품인 경우 같은 상품에서 할인 상품이 2개는 있을수 없음.
결론 -> 상품은 다시 노출 가능, 할인 상품은 노출 불가. 상품과 할인 상품의 구별 필요
작성자: (가)와 (나) 중 어느 쪽인지, 또는 다른 뜻인지 적어 주세요.
사용자: 가
반영: REQ-10, 상태와 전이 "재노출" (2회차)
